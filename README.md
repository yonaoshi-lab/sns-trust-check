# SNS信頼度チェッカー

X / Instagram / Threads のURLを貼るだけで、その人の実績主張を「証拠の等級」で検証し、
**本物か、自己申告だけか、典型的な誘導パターンか**を A〜E で判定するプロンプトです。

- 無料・改変自由・再配布自由（CC0）
- APIキー不要。Web検索ができるAI（ChatGPT 検索ON／Claude／Gemini／Perplexity／Grok）に貼るだけ
- 判定基準はすべて `PROMPT.md` に書いてあります。隠しロジックはありません

## 使い方

1. `PROMPT.md` を開き、「=== ここから ===」以降を丸ごとコピーしてAIに貼る
2. 最後の「対象URL:」に調べたいアカウントのURLを貼る（複数可）
3. AIが読めないページがあっても、読める範囲で仮判定が出ます。確定させたい時は、AIが最後に列挙する「貼ってほしいもの」（プロフィール文・投稿）をコピペして追加で渡す

X は外部のAIからのアクセスを拒否することが多いですが、プロンプト内に代替経路（公開の埋め込み用タイムライン）を書いてあるので、URLだけで投稿を読めます。Threads もURLだけで読めます。Instagram はログイン壁で本文が読めないため仮判定になります。確定させたい時は、プロフィール画面と投稿のスクリーンショットを添付してください（プロンプトは添付画像を「読めたページ」として扱います）。

## 判定の仕組み（要約）

| 等級 | 意味 |
|---|---|
| L4 | 本人が改ざんできない第三者の記録（App Store・GitHub・法人番号・クラウドソーシングの評価・報道） |
| L3 | 実在する第三者の言及 |
| L2 | 本人発だが誰でも検証できる一次物（動くプロダクト・記事そのもの・動画デモ） |
| L1 | 本人が出した画像・数字（スクショ・ダッシュボード） |
| L0 | 文字だけ |

L1以下しかない主張は、何件あっても「自己申告」として扱います。
主な主張の最高等級と、赤旗（誘導パターン）・緑旗（信頼パターン）の数で A〜E が決まります。

| 判定 | 意味 |
|---|---|
| A | 検証済み実績あり |
| B | 概ね信頼できる |
| C | 判断材料不足（悪いという意味ではない） |
| D | 自己申告のみ・注意 |
| E | 典型的な誘導パターンに一致 |

`example-fictional.md` に架空のアカウントで作った出力例があります。実在の人物の診断結果は含めていません。

## 免責と使う上でのお願い

- このプロンプトは**公開情報から証拠の等級を整理する道具**です。人物の善悪や違法性を判断するものではありません
- 出力には「詐欺」「商材屋」と断定しないルールが組み込まれています。公開する場合もその表現を崩さないでください
- 診断結果を第三者に公開するかどうか、その内容についての責任は、公開した利用者にあります
- LINE登録・DM・購入・ログインは行わない設計です。公開範囲の情報だけで判定します
- C判定は「情報が足りない」という意味です。追加情報で上下します
